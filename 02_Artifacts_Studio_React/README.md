# 🎨 02 | Artifacts Studio (React)

Welcome to the visual engine of the Suite. 

Claude's "Artifacts" feature allows the AI to generate, render, and iterate on standalone code snippets—especially UI components—in real-time. This folder contains templates designed to trigger Claude's Artifact rendering capabilities perfectly.

### 🎯 What's Inside?
- **`CIS_Dashboard_Template.jsx`**: A modular React/TailwindCSS template. It demonstrates how to ask Claude to generate a functional, interactive dashboard component that renders immediately in the browser via the Artifacts window.

### 🛠️ How to Use It
1. Use this file as a reference architecture.
2. Prompt Claude: *"Using the React and Tailwind principles shown in `CIS_Dashboard_Template.jsx`, create a new Dashboard Artifact for [Your Use Case]."*
3. Watch Claude instantly render a beautiful, responsive UI.

> **Pro Tip:** Always specify the tech stack explicitly in your prompts (e.g., `React`, `Lucide Icons`, `Tailwind CSS`, `Recharts` for charts) to get production-ready Artifacts.
